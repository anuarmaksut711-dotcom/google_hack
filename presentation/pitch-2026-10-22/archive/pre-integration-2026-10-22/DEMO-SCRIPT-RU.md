# Демонстрация: 2–3 минуты

Основной готовый показ — локальный, с явно синтетическими моделью/Moodle/Google.
Он проверяет код UI, MCP, solver, согласие и verify; не качество Gemini OCR и не GCP.

Запуск из корня: `PYTHONPATH=src:. .venv-pitch/bin/python tests/pitch_ui/browser_fixture.py`.
Открыть `http://127.0.0.1:8963/fixture/start`. Часы стенда: 17.10.2026 21:00 Asia/Almaty.
Не запускайте этот fixture в облаке. Файл `samples/synthetic-weekly-classes.pdf`
содержит одну искусственную пару в субботу 22:00–22:20, без дат действия.

| Время | Действие и реплика |
| --- | --- |
| 0:00–0:20 | «CampusPulse собирает дедлайны Moodle и помогает найти время для учёбы. Сейчас показываю локальный тестовый сценарий». Открыть «Мои задания»: Homework, срок 18.10 03:00. |
| 0:20–0:55 | Открыть «Пары и время для учёбы». Выбрать синтетический PDF, нажать «Распознать пары». «Это черновик, а не сохранённое расписание». Проверить субботу 22:00–22:20, заполнить 17.10–24.10, отметить проверку и сохранить. |
| 0:55–1:20 | Сохранить 90 минут на Homework и окно 17.10 22:00–18.10 02:00. «Пары исключатся автоматически; сами пары в Calendar не переносятся». |
| 1:20–1:45 | Перейти к «Предложенному расписанию», нажать «Составить расписание». «Первый блок начинается в 22:30: пара до 22:20 исключена, граница округлена безопасно. Существующая занятость Calendar тоже учитывается». |
| 1:45–2:10 | Просмотреть интервалы и точную версию, нажать «Подтвердить расписание», затем отдельно «Применить в Google Calendar». «Согласие относится только к этой версии». |
| 2:10–2:40 | Дождаться «Расписание проверено». Открыть журнал `apply_plan`, `verify_plan`: показать фактические результаты. «Запись проверяется независимым чтением, а не ответом модели». |
| 2:40–2:55 | Перезагрузить страницу: результат восстановился. «Это локальная проверка с тестовым Calendar. Для облака нужны финальный rollout и живая приёмка». |

Если распознавание недоступно — заполнить пару вручную, проговорить отказ и продолжить.
Если запись unknown/partial/applied_unverified/verification_failed — показать этот статус,
перечитать состояние, не называть успехом и не повторять запись вслепую.

Облачный показ допускается только после штатного входа в опубликованную финальную
версию и разрешения на выделенный тестовый Calendar. Сверить SHA и live receipt
с актуальным handoff Мерея. Его read-only study-agent сам по себе Calendar не меняет.
