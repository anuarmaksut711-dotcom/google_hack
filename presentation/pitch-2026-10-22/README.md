## Граница подтверждённого

Handoff `setup/PITCH-CLOUD-HANDOFF.md` фиксирует успешную публикацию read-only
релиза `1382f49` и реальный вход 22 октября. Agent Engine прочитал 15 записей
Moodle и вызвал `read_schedule`. Пары у того пользователя ещё отсутствовали,
поэтому ответ сохранил статус черновика. Этот запуск не создавал Calendar events.

Новая объединённая версия локально проверена с тестовыми внешними сервисами:
импорт в черновик, сохранение пар, чат через Engine transport, ConnectedPlans,
точное согласие, apply, verify и повтор без дубликатов. Облачная приёмка новой
записи Calendar и распознавания ещё не завершена. Итоговый rollout receipt
имеет приоритет над этим промежуточным статусом.

Скриншот одного дня добавляет только видимые пары. Следующие файлы дополняют
черновик с удалением точных дублей. Студент проверяет всю неделю и даты действия,
затем явно сохраняет. Даты без явного полного периода в файле модель не угадывает.
Пары становятся занятыми интервалами, но автоматически в Calendar не попадают.

Локальный полный pytest: **2472 passed, 0 skipped**, 171.44 с. После трёх небольших
правок текста прошли 27 целевых тестов. Новый Cloud Build gate фиксируется отдельно.
Реальный Vertex Gemini через адаптер распознал один скриншот: четыре пары
понедельника, даты null, без добавления других дней. Это не HTTP-приёмка сайта
и не измеренная точность OCR.

## Локальная демонстрация

Из корня репозитория:

```sh
PYTHONPATH=src:. .venv-pitch/bin/python tests/pitch_ui/connected_browser_fixture.py
```

Открыть `http://127.0.0.1:8964/fixture/start`. На экране остаётся предупреждение
о тестовых Google, Moodle, AI и Calendar. Часы: 17.10.2026, 21:00 Asia/Almaty.
Это композиция cloud-приложения с синтетическими внешними границами, не облачный приёмочный запуск.
Старый recovery fixture на порту 8963 относится к отдельному режиму.

## Повторная сборка

```sh
"$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node" presentation/pitch-2026-10-22/build-deck.mjs
```

Генератор использует bundled `@oai/artifact-tool`, Node.js, Python и LibreOffice,
не устанавливая зависимости. Финализатор проверяет PPTX, затем генератор обновляет
стабильные файлы в `output/`. Нативные объекты сценария, архитектуры и таблицы
остаются редактируемыми. PowerPoint на этой машине для просмотра не использовался.

Исторические отчёты прежней UI-ветки находятся в [архиве](archive/pre-integration-2026-10-22/README.md).
Личные скриншоты, Moodle URL, токены, Calendar IDs и приватные конфигурации в комплект не входят.
