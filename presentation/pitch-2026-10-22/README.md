## Повторная сборка

Нужны bundled Node.js, Python, `@oai/artifact-tool` и служебные файлы навыка Presentations. Путь версии runtime по умолчанию соответствует этой машине. Его можно задать через `RUNTIME_NODE_MODULES`, `RUNTIME_PYTHON`, `PRESENTATIONS_SKILL_DIR` и `SOFFICE`.

Из этой папки:

```sh
"$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node" build-deck.mjs
```

Скрипт рендерит все слайды, экспортирует PPTX, запускает package/layout/font/import-проверки и делает PDF. Финализатор проверяет новый внутренний кандидат в уникальной папке `.build/`. Затем скрипт копирует его без изменений поверх своих стабильных файлов в `output/`. Чтобы сохранить отдельную версию, передайте новое имя первым аргументом, например `CampusPulse-AI-Pitch-r2`.

В bundled Artifact Tool native PDF export завершился ошибкой отсутствующего `#standard-fonts/Helvetica`. Поэтому PDF собран bundled LibreOffice из финализированного PPTX. Локальный `fontconfig` указывает системные шрифты, чтобы сохранить Helvetica Neue. Исходники runtime и установленные зависимости не менялись.

## Проверка готового комплекта

Для финального PPTX прошли проверки пакета, геометрии, заголовков, шрифта и повторного импорта Artifact Tool. Во всех категориях 0 findings. Подтверждены 7 слайдов, 7 страниц PDF и нативная таблица на слайде 5.

Каждый слайд PNG просмотрен в полном размере. Финальный PDF отдельно отрендерен Poppler, все 7 страниц просмотрены. Кириллица, переносы, таблица, схемы и легенды читаются без обрезки и пересечений. PDF содержит извлекаемый текст и встроенные HelveticaNeue/HelveticaNeue-Bold. В PowerPoint файл не открывался, поэтому проверка нативного PowerPoint-рендера не заявляется.

Независимая проверка формулировок исправила два риска: исторический статус recovery больше не выдаётся за свежую облачную проверку, а речь не обещает отсутствие галлюцинаций. Полный личный cloud apply/verify остаётся явно неподтверждённым.
